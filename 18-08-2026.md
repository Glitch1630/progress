npm- Node Package Manager- is a packet management system usd in Node.js

It allows devolpers to:

- find packages
- install packages
- update packages
- remove packages
- manage project dependencies
- run project-related commands

**packageS**- is a collection of reusable code so which is organized so that other people can use it in there projects

`npm init -y` creates package.json which is a file that describes the project

npm init asks questions such as :

- project name
- version
- description
- entry point
- author
- license
  it does not install packages

JavaScript Object Notation - is a structured text format used to represent data .

It is used for configuration files and communication between application

I installed the required package using :

```npm install unique-names-generator```

npm then installed the package into :

`node_modules/`-[contains the actual installed packages that my  project uses.]

 and updated :
 
  - _package.json_
  - _package-lock.json_
_package.json_ contains project information and the project's dependencies.

It contains information about my project, such as:

- project name
- version
- description
- scripts
- dependencies

_package-lock.json_ records the exact dependency resolution and dependency tree created by npm.

```**In short**

package.json:

What does my project require?

package-lock.json:

What exact dependency resolution did npm create?
```
