I build a command line Todo list using JavaScript and Node.js .

In this program the user can 
- Add a task
- List all task
- Mark task as completed 
- Remove the task

also it stores the data permanently in a JSON file 

While doing this cli todo i learned new concepts such as 

- ``fs[File System]`` 
    - ``fs.existsSync()``-checks whether a particular file or directory exists.

    - ``fs.readFileSync()``- reads the contents of a file .

    - ``fs.writeFileSync()`` - It takes the data we want to save and writes it into the specified file.

- ``JSON.stringfy()`` - converts it into JSON text that can be written to a file.

- ``JSON.parse()`` - It converts JSON text into JS data.

- ``splice()`` - it lets an item to be removed from a specific array position .

- fs.existsSync() here we needed to whether todos.json exist when we start the program . 
    
- pop() removes an item from the end of the array
