Today I learned how computers communicate over a network and how a Node.js program can act as an HTTP server.

First, I understood why protocols are needed. When two computers communicate, they need common rules so that both sides understand how data should be sent and received.

I learned that IP is mainly responsible for addressing and routing data toward the correct machine. An IP address identifies the machine, while a port number identifies a particular service or application running on that machine.

I also learned about TCP. IP alone does not guarantee that data will arrive correctly. TCP provides reliable and ordered communication and can deal with problems such as missing data.

Then I learned about HTTP, which works at the application level. HTTP gives meaning to the messages being exchanged between a client and a server.

HTTP Request and Response
---------------------------
The client sends an HTTP request to the server, and the server sends an HTTP response back.

A request can contain:

Method – what action the client wants to perform
Path/URL – which resource is being requested
Headers – additional information about the request
Body – the actual data being sent

For example:

GET /about

Here:

GET   → method
/about → path

I also learned that req.url can contain query parameters, such as:

/about?name=anu

Here /about is the path and name=anu is the query parameter.

HTTP Methods

The main HTTP methods I learned are:

GET     → retrieve data
POST    → create/send data
PUT     → replace data
PATCH   → partially update data
DELETE  → remove data

I learned that the method tells the server what action is being requested.

HTTP Status Codes
------------------
I learned that the server uses status codes to tell the client what happened.

Examples:

200 → request successful
201 → resource created
400 → bad request
404 → resource not found
500 → server error

FTP
-----
I also learned that FTP means File Transfer Protocol. It is a protocol designed around transferring and managing files between computers. HTTP and FTP solve different communication problems, although HTTP can also be used to transfer files.
