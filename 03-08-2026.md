I learned that there are **4 types of loops** in JavaScript.

* `for` loop – used when I want to access elements using their index (mainly for arrays).
* `for...of` – used when I don't care about the index and only want the values (mainly for arrays).
* `for...in` – used to access the keys (property names) of an object.
* `while` – runs until a condition becomes false.

I also learned some basic array methods.

* `push()` adds an element to the end.
* `pop()` removes the last element.
* `unshift()` adds an element to the beginning.
* `shift()` removes the first element.
* `splice()` can add, remove, or replace elements in the middle of an array.

I wrote a program to find the sum of an array using both a `while` loop and a `for` loop.

I also wrote a function `getEvenSum` to find the sum of even numbers in an array.

Finally, I solved the colors problem by changing `"Green"` to `"Yellow"`, removing `"Blue"`, and adding `"Black"` using array methods.
